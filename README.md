# RaZf Bank 🏦

A simple, menu-driven banking application built using Python. This is my first beginner-level Python project, created while learning **functions, conditional statements, loops, user input, and basic variable management**.

## 📌 About the Project

RaZf Bank is a basic console-based banking program that allows users to check their account balance, deposit money, and withdraw money through an interactive menu.

The main purpose of this project is to apply the Python concepts I have learned so far and gain practical programming experience.

## ✨ Features

- **Check Balance:** Display the current account balance.
- **Deposit Money:** Deposit a positive amount into the account.
- **Withdraw Money:** Withdraw money if the balance is sufficient.
- **Input Validation:** Prevent deposits and withdrawals of zero or negative amounts and handle insufficient balance.
- **Interactive Menu:** Choose between different banking operations.
- **Exit Option:** Safely exit the application.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Concepts Used:** Functions, `if-elif-else` statements, `while` loop, user input, global variables, arithmetic operations, and formatted strings (f-strings).

## 🚀 How to Run

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

Replace `<your-repository-url>` with the URL of this GitHub repository.

### 2. Open the Project Folder

```bash
cd <repository-folder-name>
```

### 3. Run the Python File

```bash
python razf_bank.py
```

If your Python file has a different name, replace `razf_bank.py` with the actual filename.

Make sure Python 3 is installed on your system.

This project is intended for learning purposes only. It stores the balance in memory, so the balance resets when the program is restarted. It does not use a real banking system, database, or authentication mechanism.

**Do not use this program to manage real money.**
